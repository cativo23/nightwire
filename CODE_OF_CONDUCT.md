# Code of conduct

Nightwire adopts the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/)
as its code of conduct. It applies to everyone taking part in this project: in issues, pull
requests, discussions, reviews and any other project space, and when representing the project
elsewhere.

Read the full text at the link above. In short: be respectful and constructive, assume good
faith, and do not harass, demean or exclude anyone.

## Reporting

Report conduct concerns to the maintainer via GitHub ([@cativo23](https://github.com/cativo23)).
Ask for a private channel first if the details are sensitive. The maintainer aims to handle reports
confidentially and to follow the enforcement and repair guidance in the Contributor Covenant.
