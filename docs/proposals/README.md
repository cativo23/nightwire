# Proposals

Improvement ideas for Nightwire, one file each. They started as `SUGGESTIONS.md`, written while
building the SYNAPSE ops-center demo, and are ordered by impact. [roadmap.md](../roadmap.md)
sequences the open ones by semver impact.

To propose something new, add `NNN-short-slug.md` with the next number, using the same headings:
status, problem, suggestion.
