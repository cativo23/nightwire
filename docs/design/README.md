# Design

Reserved for the next sub-project: the more mature visual direction for Nightwire (calmer, less
sci-fi, with a real motion system such as accordions that open and close smoothly), applied to the
whole system rather than shipped as a separate theme. It keeps Nightwire's own fonts.

Design decisions, references and motion specs go here as that work starts. Until then, the
current visual language is described in [`DESIGN.md`](../../DESIGN.md) at the repo root, and the
known issues it inherits are listed in [architecture/intensity.md](../architecture/intensity.md).
